# Sheet Ordering Mode Dropdown

## Overview
Add a dropdown to the Drawing Dock pane letting the user choose between two sheet ordering modes for the "Rename Sheets" command. Persist the choice in AddinSettings.

## The Two Modes

1. **Group by Assembly** (Interleaved): Each assembly is followed by its frames and parts before moving to the next assembly.
   - `A-01 → A-01 Frames → A-01 Parts(01-05) → A-02 → A-02 Frames → A-02 Parts → ... → Sequential parts (P-001...) → NonCompliant → Empty`

2. **Parts at End** (Sequential): All assembly/frame sheets first, then all parts sheets grouped together.
   - `A-01 → A-01 Frames → A-02 → A-02 Frames → ... → All Parts sheets in order → NonCompliant → Empty`

## Changes

### 1. New enum: `SheetOrderingMode.cs` (root namespace)
```
SheetOrderingMode { GroupByAssembly = 0, PartsAtEnd = 1 }
```

### 2. `AddinSettings.cs`
- Add property: `public SheetOrderingMode SheetOrderingMode { get; set; } = SheetOrderingMode.GroupByAssembly;`
- No version bump needed (new property with default just works with JSON deserialization)

### 3. `SheetRenamerService.cs` — Options class
- Add: `public SheetOrderingMode OrderingMode { get; set; } = SheetOrderingMode.GroupByAssembly;`

### 4. `SheetRenamerService.cs` — Ordering logic
- `ReorderSheetsByName`: pass `OrderingMode` to comparator
- **PartsAtEnd mode** (current behavior): Keep existing `CompareSheetInfoForOrdering` as-is (SortGroup 0 → 2 → 1 → 3)
- **GroupByAssembly mode** (new): New comparator where structured parts (SortGroup 2 with ParentAsm) are sorted alongside their parent assembly group, after frames. Sequential parts (no ParentAsm) come after all assembly groups. NonCompliant and Empty remain last.

### 5. `DrawingDockPane.cs` — UI
- Add a `ComboBox` dropdown above the "Rename Sheets" button in the DRAWING AUTOMATION group
- Items: "Group by Assembly", "Parts at End"
- Persist selection: on change → save to `AddinSettings.Current.SheetOrderingMode`
- Load initial value from `AddinSettings.Current.SheetOrderingMode` in constructor
- Expand autoLayout from 3 rows to 4 rows, increase group height from 150px to 184px

### 6. `DrawingDockPane.cs` — RunRenameSheets
- Pass `AddinSettings.Current.SheetOrderingMode` to `SheetRenamerService.Options.OrderingMode`
